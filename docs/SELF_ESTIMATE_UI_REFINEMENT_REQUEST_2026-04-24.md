# 셀프견적 UI 추가 수정 요청서

- 작성일: `2026-04-24`
- 대상 URL: `https://zapgo-eight.vercel.app/selfest`
- 목적: 반영 완료된 셀프견적 플로우를 기준으로 브랜드 일관성, CTA 명확성, 문구 통일성, 상담 전환율을 높이기 위한 추가 UI 수정 요청

## 1. 공통 수정 사항

- 1페이지, 2페이지, 3페이지 오른쪽 상단에 `에너지잡고 붉은색 로고`를 배치해 주세요.
- 각 페이지의 로고 위치와 크기는 동일하게 맞춰 주세요.
- 주요 액션 버튼과 선택 상태에 사용하는 붉은 색상은 임의 지정하지 말고, `에너지잡고 로고에서 추출한 브랜드 레드 컬러`를 사용해 주세요.

## 2. 하단 버튼 문구 통일

전체 페이지 하단 버튼 문구를 아래와 같이 통일해 주세요.

- `카톡문의`
- `전화문의`
- `방문견적요청`

적용 페이지:

- 1페이지
- 2페이지
- 3페이지

동작 정의:

- `카톡문의`: 카카오채널 채팅방으로 연결
- `전화문의`: 전화 연결
- `방문견적요청`: 방문견적 요청 화면 또는 모달로 연결

## 3. 1페이지 수정 사항

- 오른쪽 상단에 `에너지잡고 붉은색 로고`를 배치해 주세요.
- 불편 사항을 선택했을 때 현재 검은색으로 바뀌는 선택 상태를 `브랜드 레드 컬러`로 변경해 주세요.
- `다음` 버튼이 활성화될 때도 `브랜드 레드 컬러`로 변경해 주세요.

## 4. 2페이지 수정 사항

- 오른쪽 상단에 `에너지잡고 붉은색 로고`를 배치해 주세요.
- `예상 견적 보기` 버튼 색상을 `브랜드 레드 컬러`로 변경해 주세요.

참고:

- `개수 세는 방법 보기` 문구는 이미 수정 완료되었으므로 추가 변경하지 않아도 됩니다.

## 5. 3페이지 수정 사항

- 오른쪽 상단에 `에너지잡고 붉은색 로고`를 배치해 주세요.
- `시공 방식을 선택하시면 예상 견적을 확인하실 수 있어요` 안내 박스는 `붉은색 계열`로 변경해 주세요.
- 해당 안내 문구는 `볼드체`로 적용해 주세요.

### 5.1 시공 방식 설명 문구 수정

`어떤 시공을 원하시나요?` 아래 각 시공 방식 설명 문구를 아래처럼 수정해 주세요.

- 패브릭씰러 시공: `창문 탈거 / 패브릭씰러 / 4면 시공`
- 일반 모헤어 시공: `창문 탈거 / 일반 모헤어 / 4면 시공`
- 측면 시공: `창문 미탈거 / 패브릭씰러 / 측면만 시공`

### 5.2 일반 모헤어 설명 박스 삭제

- `일반 모헤어 시공`을 선택했을 때, 아래쪽에 추가로 노출되는 설명 박스 문구는 삭제해 주세요.
- 즉, 일반 모헤어 선택 시 별도의 보조 설명 박스가 나타나지 않도록 처리해 주세요.

### 5.3 메인 CTA 수정

변경 전:

- `이 조건으로 시공 요청하기`

변경 후:

- `이 조건으로 상담 신청하기`

추가 요청:

- 버튼 색상은 `브랜드 레드 컬러`로 적용해 주세요.
- 버튼에는 `약한 펄스 애니메이션`을 적용해 주세요.
- 과한 점멸이 아니라 자연스럽고 부드러운 강조 효과 수준으로 적용해 주세요.

### 5.4 3페이지 하단 버튼 색상 분리

3페이지에서만 하단 버튼 색상을 아래처럼 각각 다르게 적용해 주세요.

- `카톡문의` 버튼: `#FEE500`
- `전화문의` 버튼: `#D1F2EB`
- `방문견적요청` 버튼: `#E5E5E5`

주의:

- 위 색상 분리는 `3페이지에만 적용`해 주세요.
- 1페이지와 2페이지 하단 버튼은 기존 공통 스타일을 유지해도 됩니다.

## 6. 상담 신청 페이지 수정

기존의 `시공 요청` 표현을 `상담 신청` 중심으로 변경해 주세요.

변경 요청:

- `시공 요청` → `상담 신청`
- `고객 정보를 입력해주세요` → `아래 정보를 제출해 주세요`
- `시공 요청 제출` → `상담 신청 제출하기`

추가 요청:

- `상담 신청 제출하기` 버튼 색상도 `브랜드 레드 컬러`로 통일해 주세요.

## 7. 뒤로가기 / 이탈 팝업 문구 수정

결과 페이지에서 뒤로가기 또는 이탈 시 뜨는 팝업 문구를 아래처럼 수정해 주세요.

변경 전:

- `시공을 요청하시겠어요?`
- `시공 요청하기`

변경 후:

- `상담을 신청하시겠어요?`
- `상담 신청하기`

`나중에 볼게요` 버튼은 그대로 유지해 주세요.

## 8. 결과 다시보기 링크 문자 발송 오류 수정 요청

현재 `결과 다시보기 링크 받기` 기능을 사용해도 문자가 오지 않습니다. 아래 항목들을 점검하고 수정해 주세요.

### 8.1 점검 요청 사항

- 문자 발송 API가 실제로 호출되는지 확인
- 프론트 요청은 정상이나 서버/API에서 실패하는지 확인
- 문자 발송 서비스 연동 상태 확인
- 환경변수 누락 여부 확인
- 발신번호, 템플릿, 국가코드, 전화번호 포맷 오류 여부 확인
- 실패 시 콘솔 에러 또는 서버 로그 확인
- 링크 생성 시 결과 상태값이 제대로 포함되는지 확인

### 8.2 사용자 피드백 추가

문자 발송 성공 시:

- `문자 발송이 완료되었습니다`

문자 발송 실패 시:

- `문자 발송에 실패했습니다. 다시 시도해 주세요`

### 8.3 링크 동작 확인

- 문자로 발송되는 링크가 실제로 결과 페이지로 정상 이동하는지 확인해 주세요.
- 가능하면 고객이 선택한 시공 방식 및 옵션 상태가 유지된 링크로 연결해 주세요.

## 9. 최종 요청 요약

이번 추가 수정 요청의 핵심은 아래와 같습니다.

- 오른쪽 상단 브랜드 로고 추가
- 브랜드 레드 컬러를 로고에서 추출해 버튼/선택 상태에 적용
- 하단 버튼 문구를 `카톡문의 / 전화문의 / 방문견적요청`으로 통일
- 3페이지 안내 박스 및 메인 CTA의 시각적 강조 강화
- 결과 페이지의 상담 전환 문구를 `시공 요청`에서 `상담 신청` 중심으로 변경
- 결과 다시보기 문자 발송 오류 수정
