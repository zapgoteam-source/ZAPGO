# 셀프견적 퍼널 개편 최종 수정 요청서

- 버전: `v2 최종`
- 목적: 셀프견적 과정을 더 쉽고 빠르게 만들어 견적 확인율을 높이고, 결과 페이지에서 고객이 직접 시공 방식과 옵션을 조정하며 시공 요청으로 이어지도록 개선

## 1. 개편 목표

- 입력 단계의 복잡도 축소
- 결과는 먼저 보여주고, 리드 수집은 그 이후로 이동
- 결과 페이지에서 고객이 직접 금액을 조정하게 하여 체류시간과 이해도 상승
- 결과 이탈 고객은 문자 링크 저장으로 전환
- 상담 CTA를 고객이 직관적으로 이해하는 구조로 정리

## 2. 전체 플로우

변경 후 플로우:

1. 1페이지: 불편 사항 선택
2. 2페이지: 주택 정보 최소 입력
3. 3페이지: 시공 방식 선택 + 옵션 조정 + 실시간 예상 견적 확인
4. 결과 페이지 이탈 시 1회 팝업 노출
5. `나중에 볼게요` 선택 시 연락처 입력 후 결과 링크 문자 발송

## 3. 1페이지

기존 구조는 유지하되 하단 CTA를 변경한다.

유지:

- 불편 사항 다중 선택
- 다음 버튼

하단 CTA 변경:

- `카톡상담`
- `전화상담`
- `방문견적요청`

동작:

- `카톡상담`: 카카오채널 채팅방 이동
- `전화상담`: 전화 연결
- `방문견적요청`: 방문견적 요청 화면 또는 모달 이동

## 4. 2페이지 수정 사항

### 4.1 입력 항목

2페이지에서는 아래 두 항목만 입력받는다.

- 평형 입력
- 창짝 개수 입력

받지 않는 항목:

- 연락처
- 지역
- 추가옵션

### 4.2 문구 변경

변경 전:

- `창짝 수 입력`
- 입력 단위 `짝`
- `창짝이란?`
- `다음`

변경 후:

- `창짝 개수 입력`
- 입력 단위 `개`
- `개수 세는 방법 보기`
- `예상 견적 보기`

참고:

- 내부 데이터 구조는 기존 창짝 로직 유지 가능
- UI 문구만 고객 친화적으로 변경

### 4.3 제거할 요소

2페이지에서 아래 옵션 제거:

- 프리미엄 보양
- 방충솔루션

위 옵션은 결과 페이지로 이동한다.

### 4.4 하단 CTA

2페이지 하단에도 동일하게 유지:

- `카톡상담`
- `전화상담`
- `방문견적요청`

## 5. 3페이지 결과 화면 수정 사항

### 5.1 초기 상태

결과 페이지는 즉시 진입 가능하지만, 첫 진입 시 시공 방식은 미선택 상태로 시작한다.

초기 노출 방식:

- 금액을 먼저 보여주지 않음
- 빈 상태 + 안내문구만 표시

노출 문구:

- `시공 방식을 선택하시면 예상 견적을 확인하실 수 있어요`

즉, 총액 영역은 선택 전까지 확정 숫자를 표시하지 않는다.

### 5.2 시공 방식 선택 UI

질문 문구:

- `어떤 시공을 원하시나요?`

버튼:

- `패브릭씰러 시공`
- `일반 모헤어 시공`
- `측면 시공`

동작:

- 시공 방식 선택 시 총액 즉시 계산
- 선택 변경 시 총액 실시간 갱신

### 5.3 추가옵션 UI

2페이지에서 제거한 추가옵션을 결과 페이지에 배치한다.

옵션:

- 프리미엄 보양
- 방충솔루션

초기 상태:

- 모두 미선택

동작:

- 고객이 켜고 끌 때마다 총액 실시간 변경

### 5.4 일반 모헤어 계산 방식

일반 모헤어는 아래 방식으로 간편 계산한다.

계산식:

- `평수 × 35,000원`

표시 문구:

- `일반 모헤어 시공은 평형 기준의 간편 예상 금액으로 계산됩니다`
- `실제 창문 수와 현장 상태에 따라 일부 조정될 수 있습니다`

용도:

- 비교용/간편용 예상 견적

### 5.5 CTA 구성

결과 페이지 하단 구성:

메인 CTA:

- `이 조건으로 시공 요청하기`

보조 CTA:

- `카톡상담`
- `전화상담`
- `방문견적요청`

연출 방식:

- 메인 CTA는 하단 고정 또는 강한 강조형으로 배치
- 과한 깜빡임은 사용하지 않음
- 필요 시 약한 펄스 애니메이션만 허용

## 6. 결과 페이지 이탈 방지 팝업

### 6.1 노출 조건

결과 페이지에서 아래 행동 시 1회만 노출:

- 뒤로가기
- 페이지 이탈 시도
- 다른 페이지 이동 시도

상시 팝업 아님

### 6.2 팝업 문구

- `시공을 요청하시겠어요?`

버튼:

- `시공 요청하기`
- `나중에 볼게요`

### 6.3 버튼 동작

`시공 요청하기`

- 시공 요청 입력 화면으로 이동

`나중에 볼게요`

- 연락처 입력 모달 노출
- 연락처를 입력하면 결과 다시보기 링크를 문자로 자동 발송

## 7. 결과 다시보기 문자 발송

### 7.1 입력 항목

`나중에 볼게요` 선택 시 아래 항목만 입력받는다.

- 연락처

이름/지역은 이 단계에서 받지 않는다.

### 7.2 안내 문구

- `연락처를 남겨주시면 결과를 다시 볼 수 있는 링크를 문자로 보내드릴게요`

### 7.3 문자 발송 내용

- 결과 페이지 다시보기 링크
- 가능하면 고객이 선택한 시공 방식과 옵션 상태가 유지된 링크 사용

## 8. 공통 하단 CTA 변경

기존 `상담원 연결` 표현은 아래 3개 CTA로 변경한다.

공통 CTA:

- `카톡상담`
- `전화상담`
- `방문견적요청`

적용 화면:

- 1페이지
- 2페이지
- 3페이지

동작:

- `카톡상담`: 카카오채널 채팅방 이동
- `전화상담`: 전화 연결
- `방문견적요청`: 방문견적 요청 화면 또는 모달

## 9. 최종 문구 변경 정리

2페이지:

- `창짝 수 입력` → `창짝 개수 입력`
- `짝` → `개`
- `창짝이란?` → `개수 세는 방법 보기`
- `다음` → `예상 견적 보기`

3페이지:

- `시공 방식을 선택하시면 예상 견적을 확인하실 수 있어요`
- `어떤 시공을 원하시나요?`
- `패브릭씰러 시공`
- `일반 모헤어 시공`
- `측면 시공`

이탈 팝업:

- `시공을 요청하시겠어요?`
- `시공 요청하기`
- `나중에 볼게요`

문자 링크 모달:

- `연락처를 남겨주시면 결과를 다시 볼 수 있는 링크를 문자로 보내드릴게요`

공통 CTA:

- `카톡상담`
- `전화상담`
- `방문견적요청`

## 10. 확정된 결정사항

- 결과는 먼저 보여준다
- 2페이지에서는 평형 + 창짝 개수만 입력한다
- 결과 페이지에서 시공 방식을 고르게 한다
- 결과 페이지 첫 진입 시 시공 방식은 미선택 상태로 시작한다
- 시공 방식 선택 전에는 금액을 보여주지 않고 안내문구만 노출한다
- 추가옵션은 결과 페이지로 이동한다
- 추가옵션은 모두 미선택 상태로 시작한다
- 결과 이탈 시 1회 팝업을 띄운다
- 팝업은 `시공 요청하기 / 나중에 볼게요` 구조로 간다
- `나중에 볼게요`를 누르면 연락처만 입력받는다
- 결과 다시보기 링크를 문자로 자동 발송한다
- 일반 모헤어는 `평수 × 35,000원` 간편 계산으로 간다
- 하단 CTA는 `카톡상담 / 전화상담 / 방문견적요청`으로 통일한다
- `개수 세는 법` 문구는 `개수 세는 방법 보기`로 확정한다
