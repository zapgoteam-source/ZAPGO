# ZAPGO 셀프견적 UX/UI 개선 기획안

- 작성일: 2026-05-16
- 목표: 견적 확인 고객의 이탈을 줄이고 상담 신청 전환을 높인다.
- 현재 판단: 기존 3단계 퍼널은 기능은 충분하지만, 고객이 보상을 보기 전에 화면 전환이 많고, 견적 확인 후 상담 신청까지 다시 별도 단계로 이동해야 해 전환 열기가 식을 수 있다.

## 1. 핵심 전략

### 1.1 페이지 수 축소

기존:

1. 불편 사항 선택
2. 주택 정보 입력
3. 견적 확인
4. 상담 신청

개편:

1. 빠른 입력 화면
2. 견적 확인 + 상담 전환 화면

### 1.2 퍼널 원칙

- 고객이 가격을 보기 전에는 최소 정보만 받는다.
- 견적을 본 직후 상담 신청이 가장 자연스럽게 보이게 만든다.
- 상담 신청은 별도 업무처럼 느껴지지 않고, 견적 확인의 다음 행동처럼 이어져야 한다.
- 설명은 줄이고, 선택은 빠르게, 확신은 강하게 준다.

## 2. 현재 퍼널의 주요 병목

### 2.1 첫 보상까지 거리가 있다

현재는 고객이 예상 금액을 보기 전에 최소 두 개의 화면을 통과한다. 모바일에서 불필요한 폼 길이와 단계 증가는 이탈을 키운다.

### 2.2 결과 확인 후 전환이 한 번 끊긴다

견적을 본 다음 다시 상담 신청 페이지로 이동해야 한다. 고객 입장에서는 “가격 확인”이라는 1차 목적을 이미 달성했기 때문에, 별도 페이지 이동은 추가 과업처럼 느껴질 수 있다.

### 2.3 유입 목적과 첫 화면 메시지가 더 강하게 맞물릴 여지가 있다

광고, 카카오, 검색 등에서 들어온 사용자는 대부분 “얼마인지 빨리 알고 싶다”는 의도로 들어온다. 첫 화면에서 이 기대를 더 직접적으로 확인시켜 줄 필요가 있다.

## 3. 목표 UX 구조

## 3.1 화면 A: 빠른 입력 화면

### 목적

30초 안에 예상 견적을 볼 수 있다는 감각을 주고, 필요한 최소 입력만 받는다.

### 포함 요소

1. 헤드라인
   - `30초 만에 우리 집 예상 견적 확인`
2. 보조 문구
   - `불편한 증상과 기본 정보만 알려주시면 바로 계산해드릴게요`
3. 불편 사항 선택
   - 먼지날림 / 외풍유입 / 벌레유입 / 냉난방비 / 소음유입 / 악취유입
4. 평형 입력
5. 창짝 개수 입력
6. 하단 고정 CTA
   - `내 예상 견적 보기`
7. 보조 CTA
   - 카톡문의 / 전화문의 / 방문견적요청

### UX 포인트

- 한 화면 안에서 위에서 아래로 자연스럽게 끝난다.
- 입력 완료 전에도 “예상 견적까지 남은 입력”이 적다는 느낌을 준다.
- 추천 시공은 긴 설명이 아니라, 선택 직후 간단한 태그 형태로만 보여준다.
- 자동 재생 영상은 제거하거나 접은 상태로 두고, `시공 방식 30초 영상 보기`처럼 선택형으로 바꾼다.

## 3.2 화면 B: 견적 확인 + 상담 전환 화면

### 목적

가격을 보여주고, 바로 상담 신청까지 이어지게 한다.

### 상단

- `예상 견적`
- 선택한 시공 방식에 따른 총액
- `참고용 예상 금액이며 현장 상황에 따라 달라질 수 있습니다`

### 중단

- 시공 방식 선택 카드
  - 패브릭씰러 시공
  - 일반 모헤어 시공
  - 측면 시공
- 옵션 토글
  - 프리미엄 보양
  - 방충솔루션
- 선택 변경 시 총액 실시간 반영

### 하단

#### 1단계 노출

- 고정 CTA:
  - `이 조건으로 상담 신청하기`

#### CTA 클릭 후 같은 화면에서 확장

- 이름
- 연락처
- 주소
- 희망 일정
- 요청사항

#### 제출 버튼

- `상담 신청 완료하기`

### UX 포인트

- 폼을 처음부터 전부 펼쳐두지 않는다.
- 고객이 가격을 본 뒤, 전환 의사가 생긴 시점에만 필요한 입력을 드러낸다.
- 이렇게 하면 3페이지와 상담 신청을 “기능적으로는 병합”하면서도, 한 화면에 너무 많은 부담을 얹지 않을 수 있다.

## 4. 유입 UX 개선

### 4.1 메시지 매칭

유입 채널마다 첫 화면 문구를 맞춘다.

- 광고 유입:
  - `우리 집 창문 시공, 얼마인지 바로 확인`
- 대리점 링크 유입:
  - `OO대리점 전용 예상 견적`
- 카카오 유입:
  - `상담 전에 예상 금액부터 확인해보세요`

### 4.2 신뢰 장치

첫 화면에서 너무 많은 설명 대신, 짧은 신뢰 요소를 배치한다.

- `누적 상담 000건`
- `현장 실측 후 최종 확정`
- `전화 상담 없이도 먼저 금액 확인 가능`

### 4.3 이탈 방지보다 이탈 전환

단순한 뒤로가기 팝업보다 아래가 더 중요하다.

- 견적 화면에서 문자 저장 CTA
  - `결과를 문자로 받아두기`
- 상담 신청을 망설이는 고객을 위한 보조 경로
  - `방문 견적 먼저 요청하기`
  - `카톡으로 사진 보내고 상담받기`

## 5. 최신 UI 디자인 방향

### 5.1 시각 언어

- 모바일 퍼스트
- 넓은 여백
- 카드 남발보다 섹션 중심
- 큰 숫자와 짧은 문장
- 브랜드 레드 중심의 제한된 컬러 시스템
- 보조색은 크림, 웜그레이, 차콜 계열

### 5.2 컴포넌트 스타일

- 상단 헤더는 얇고 간결하게
- 입력 필드는 높게, 터치 영역 넓게
- 라디오/체크는 버튼형 선택지로
- 가격은 크고 안정적으로
- 하단 CTA는 스크롤 중에도 사라지지 않게

### 5.3 정서적 톤

- 기술 설명보다 “이해되는 화면”
- 전문성은 복잡함이 아니라 명료함으로 전달
- 고객이 `모르겠음`을 선택해도 불안하지 않게 설계

## 6. 추천 플로우

```text
유입
 ↓
빠른 입력 화면
 - 증상 선택
 - 평형
 - 창짝 수
 ↓
견적 + 상담 화면
 - 시공 방식 선택
 - 옵션 조정
 - 총액 확인
 - 상담 신청 폼 확장
 ↓
신청 완료
```

## 7. A/B 테스트 우선순위

### 1차

- 기존 3단계 vs 2단계
- 영상 자동 노출 vs 선택형 영상
- 상담 신청 별도 페이지 vs 같은 페이지 확장 폼

### 2차

- 첫 화면 헤드라인
- CTA 문구
- 견적 노출 전 기본 시공 방식 자동 선택 여부
- 문자 저장 CTA 위치

## 8. 핵심 지표

- 랜딩 → 첫 입력 시작률
- 빠른 입력 완료율
- 견적 도달률
- 견적 화면 체류 시간
- 상담 신청 CTA 클릭률
- 상담 신청 완료율
- 문자 저장률
- 방문 견적 요청률

## 9. 추천 결론

가장 우선할 개편은 아래 세 가지다.

1. 1페이지와 2페이지를 합쳐 첫 보상까지의 거리를 줄인다.
2. 3페이지와 상담 신청을 단순 병합하지 말고, 같은 화면 안에서 점진적으로 연결한다.
3. 첫 화면을 “설문 시작”이 아니라 “즉시 견적 확인”의 감각으로 재설계한다.

이렇게 바꾸면 고객은 더 빨리 가격을 보고, 가격을 본 바로 그 자리에서 더 자연스럽게 상담으로 넘어갈 수 있다.

## 10. 상세 와이어프레임

## 10.1 화면 A: 빠른 입력 화면

```text
┌────────────────────────────┐
│ 로고                 문의   │
│                            │
│ 30초 만에                  │
│ 우리 집 예상 견적 확인      │
│                            │
│ 불편한 점을 골라주세요      │
│ [먼지] [외풍] [벌레]         │
│ [냉난방비] [소음] [악취]     │
│                            │
│ 주택 정보                  │
│ [ 25 ] 평                  │
│ [ 10 ] 개                  │
│                            │
│ 추천: 패브릭씰러 · 방충솔루션 │
│                            │
│ ─────────────────────────  │
│ [ 내 예상 견적 보기 ]        │
│ 카톡문의 · 전화문의 · 방문견적 │
└────────────────────────────┘
```

### 화면 A 세부 규칙

- 첫 스크린 안에 헤드라인, 증상 선택, 핵심 입력 2개, CTA까지 모두 보이게 한다.
- 입력이 모두 끝나면 CTA를 즉시 활성화한다.
- 평형/창짝 수는 숫자 키패드가 바로 열리도록 한다.
- 증상 선택 후 추천 태그가 짧게 나타나되, 화면을 밀어내지 않게 한다.
- `개수 세는 방법 보기`는 작은 텍스트 버튼으로 유지하되, 메인 흐름을 방해하지 않는다.

## 10.2 화면 B: 견적 + 상담 전환 화면

```text
┌────────────────────────────┐
│ 예상 견적                  │
│ 1,120,000원                │
│ 현장 상황에 따라 변동 가능   │
│                            │
│ 어떤 시공을 원하시나요?     │
│ [패브릭씰러] [일반모헤어]     │
│ [측면 시공]                 │
│                            │
│ 추가 옵션                  │
│ 프리미엄 보양      [ON/OFF] │
│ 방충솔루션         [ON/OFF] │
│                            │
│ 선택 요약                  │
│ 25평 · 10개 · 패브릭씰러     │
│                            │
│ [ 이 조건으로 상담 신청하기 ]│
│                            │
│ ─ CTA 클릭 후 같은 화면 확장 ─│
│ 이름                       │
│ 연락처                     │
│ 주소                       │
│ 희망 일정                  │
│ 요청사항                   │
│ [ 상담 신청 완료하기 ]       │
└────────────────────────────┘
```

### 화면 B 세부 규칙

- 총액은 화면 최상단에서 가장 먼저 보인다.
- 고객이 금액을 바꾸는 조작은 모두 총액 근처에 배치한다.
- 상담 폼은 기본 접힘 상태로 두고, CTA 클릭 후 부드럽게 확장한다.
- 연락처만 먼저 받고 나머지는 후속 상담에서 받는 `초간편 리드 모드`도 실험 가치가 있다.
- `결과를 문자로 받아두기`는 견적 요약 근처에 보조 액션으로 둔다.

## 11. 화면별 카피 초안

## 11.1 첫 화면 카피

### 기본형

- 제목: `30초 만에 우리 집 예상 견적 확인`
- 설명: `불편한 증상과 기본 정보만 알려주시면 바로 계산해드릴게요`
- CTA: `내 예상 견적 보기`

### 광고 유입형

- 제목: `우리 집 창문 시공, 얼마인지 바로 확인`
- 설명: `전화 없이도 먼저 예상 금액을 확인할 수 있어요`

### 대리점 링크 유입형

- 제목: `OO대리점 전용 예상 견적`
- 설명: `상담 전에 먼저 대략적인 금액을 확인해보세요`

## 11.2 견적 화면 카피

- 총액 제목: `예상 견적`
- 안내: `참고용 예상 금액이며, 지역과 현장 상황에 따라 최종 금액은 달라질 수 있습니다`
- 방식 질문: `어떤 시공이 가장 맞을까요?`
- CTA: `이 조건으로 상담 신청하기`
- 문자 저장: `결과를 문자로 받아두기`

## 11.3 상담 폼 카피

- 제목: `이 조건으로 상담을 이어갈게요`
- 설명: `연락 가능한 정보를 남겨주시면 담당자가 확인 후 안내드립니다`
- 완료 CTA: `상담 신청 완료하기`

## 12. 전환 설계 디테일

### 12.1 추천 기본값

초기에는 시공 방식 미선택 상태를 유지하되, 증상 기반 추천을 강하게 제시한다.

- 외풍/냉난방비/소음/악취 선택:
  - `추천` 배지: 패브릭씰러
- 먼지만 선택:
  - `추천` 배지: 측면 시공
- 벌레 포함:
  - 방충솔루션 자동 추천

단, 추천이 자동 선택으로 느껴지면 조작권을 잃었다고 느낄 수 있으므로 사용자가 직접 선택하게 한다.

### 12.2 상담 신청 마찰 줄이기

폼은 아래 두 버전으로 실험한다.

#### 버전 A: 표준형

- 이름
- 연락처
- 주소
- 희망 일정
- 요청사항

#### 버전 B: 초간편형

- 이름
- 연락처

제출 후:

- `상세 주소와 일정은 상담 시 안내드릴게요`

전환 극대화만 보면 B가 유리할 가능성이 높고, 운영 효율까지 보면 A와 비교가 필요하다.

### 12.3 이탈 대응

- 견적 화면 하단에 항상 보이는 보조 액션:
  - `결과 문자로 받기`
  - `방문 견적 먼저 요청하기`
- 뒤로가기 팝업은 마지막 방어선으로만 사용한다.
- 사용자가 이탈을 택했을 때는 압박보다 저장 제안을 한다.

## 13. 디자인 시스템 제안

### 13.1 컬러

- Primary: 브랜드 레드
- Surface: warm white / cream
- Text: charcoal
- Accent: muted yellow or mint only for 보조 정보

### 13.2 타이포

- 헤드라인: 굵고 짧게
- 숫자: 가장 큰 위계
- 설명: 최대 두 줄
- 각 섹션의 제목은 질문형보다 판단형이 좋다.

### 13.3 모션

- 페이지 전환보다 상태 변화 중심
- CTA 확장, 금액 카운트업, 추천 태그 등장 정도만 사용
- 자동 재생 영상과 과한 애니메이션은 전환 방해 요소로 본다.

## 14. 유입 UX 세분화

### 14.1 광고 랜딩

- 랜딩 직후 헤드라인과 광고 문구가 일치해야 한다.
- URL 파라미터로 캠페인/대리점/소재 유형을 받아 첫 화면 카피를 바꾼다.

### 14.2 카카오/문자 재방문

- 이전 입력값을 복원한다.
- 다시 방문한 고객에게는 첫 화면 대신 결과 화면 복귀를 우선한다.

### 14.3 대리점 유입

- `OO대리점 추천 고객 전용` 같은 맥락을 얇게 보여준다.
- 신뢰는 주되, 전체 브랜드 경험을 깨지 않게 한다.

## 18. 마이크로카피 원칙

### 써야 하는 문장

- 고객이 바로 이해하는 말
- 결과를 얻는 데 필요한 말
- 불안을 낮추는 말

### 피해야 하는 문장

- 내부 용어
- 너무 이른 판매 문구
- 고객이 선택하지 않은 불안을 먼저 주입하는 문장

### 예시

좋음:

- `전화 없이도 먼저 예상 금액을 확인할 수 있어요`
- `현장 확인 후 최종 금액은 달라질 수 있습니다`
- `결과를 문자로 받아두기`

나쁨:

- `정밀 산출을 위한 기초 정보 수집`
- `고객님의 니즈를 기반으로 최적 상품을 추천`
- `이탈 방지를 위해 연락처를 남겨주세요`

## 19. 기획상 의사결정

### 19.1 영상은 기본 비노출

현재 자동 재생 영상은 제품 이해를 돕지만, 첫 진입에서 사용자의 본래 목적을 방해할 수 있다. 영상은 아래처럼 바꾼다.

- `30초 시공 영상 보기`
- 클릭 시 모달
- 기본 자동 재생 없음

### 19.2 시공 방식은 자동 선택하지 않음

추천은 하되, 선택은 고객이 직접 하게 한다. 자동 선택은 빠르지만 “나에게 비싼 걸 밀고 있나?”라는 감정을 만들 수 있다.

### 19.3 상담 신청은 같은 페이지, 그러나 점진 노출

분리 페이지는 전환 열기를 끊고, 완전 노출 폼은 견적 화면을 무겁게 만든다. 따라서 같은 페이지 내 확장이 가장 균형이 좋다.

## 20. 성공 기준

### 정량

- 견적 도달률 상승
- 상담 CTA 클릭률 상승
- 상담 신청 완료율 상승
- 이탈 후 문자 저장률 상승

### 정성

- 고객이 첫 화면에서 서비스 목적을 즉시 이해한다.
- 견적 확인 뒤 다음 행동이 자연스럽다.
- 상담 신청이 별도 업무처럼 느껴지지 않는다.
- 브랜드가 더 현대적이고 신뢰감 있게 보인다.

## 21. 리드 퍼널 관점의 게이팅 전략

사용자 의도가 `정확한 견적 확인`보다 `호기심 → 궁금증 증폭 → 상담 전환`에 가깝다면, 연락처 입력을 견적 결과 전에 배치하는 전략은 충분히 검토할 가치가 있다.

다만 핵심은 `게이트를 둘지 말지`가 아니라, `어느 정도의 보상을 먼저 준 뒤 게이트를 세울지`다.

### 21.1 가능한 3가지 모델

#### A. 완전 오픈형

```text
입력 → 전체 견적 공개 → 상담 유도
```

- 장점: 견적 도달률이 가장 높다.
- 단점: 리드 확보율은 낮을 수 있다.
- 적합: 브랜드 검색, warm traffic, 재방문 고객

#### B. 완전 게이트형

```text
입력 → 연락처/지역 입력 → 견적 공개
```

- 장점: 리드 확보율을 강하게 높일 수 있다.
- 단점: 차가운 광고 유입에서는 결과 보기 전 이탈이 커질 수 있다.
- 적합: 리드 가치가 높고, 사용자가 이미 강한 의도를 가진 경우

#### C. 티저 후 게이트형

```text
입력 → 대략 범위/추천 방식 공개 → 연락처/지역 입력 → 상세 견적 공개
```

- 장점: 호기심을 유지하면서도 리드를 확보할 수 있다.
- 단점: 화면 설계가 더 섬세해야 한다.
- 적합: 인스타 광고, 대리점 링크, 저관여 유입

### 21.2 추천안

현재 목표가 `광고 유입의 상담 전환 극대화`라면, 기본 추천은 **C. 티저 후 게이트형**이다.

이유:

- 완전 게이트형은 너무 이른 요구로 느껴질 수 있다.
- 완전 오픈형은 결과만 보고 떠나는 사용자를 많이 만든다.
- 티저 후 게이트형은 사용자가 이미 투자한 입력을 바탕으로 궁금증이 충분히 올라온 뒤 최소 정보만 요구할 수 있다.

### 21.3 추천 플로우

```text
광고 클릭
 ↓
빠른 입력
 - 증상
 - 평형
 - 창짝 수
 ↓
티저 결과
 - 추천 시공
 - 예상 금액대 일부 공개
 - "정확한 예상 견적을 보려면 연락처와 지역을 입력해주세요"
 ↓
리드 게이트
 - 휴대폰 번호
 - 시/도 또는 시/군/구
 ↓
상세 견적
 - 총액
 - 옵션 조정
 - 상담 신청
```

### 21.4 게이트에 넣을 필드

게이트 전 최소 필드:

- 휴대폰 번호
- 지역

게이트 후 후속 수집:

- 이름
- 상세 주소
- 희망 일정
- 요청사항

이렇게 나누면 초반 마찰은 억제하면서도, 후속 상담 가능성은 충분히 확보할 수 있다.

### 21.5 지역을 먼저 받는 이유

- 실제 시공 가능 지역 여부 확인
- 대리점 라우팅
- 이후 상담 품질 향상
- 광고 효율 분석

단, `상세 주소`는 너무 이르다.  
광고 유입 초반에는 `시/도 + 시/군/구` 정도가 적절하다.

### 21.6 문구 예시

- `추천 시공은 확인됐어요`
- `정확한 예상 견적을 보려면 연락처와 지역을 입력해주세요`
- `입력하신 번호로 견적 결과도 함께 보내드릴게요`

### 21.7 반드시 실험할 것

#### 실험 1

- 오픈형 vs 티저 후 게이트형

#### 실험 2

- 전화번호만 요청 vs 전화번호 + 지역 요청

#### 실험 3

- `상세 견적 보기` vs `내 지역 기준 견적 보기`

### 21.8 판단 지표

- 입력 시작률
- 게이트 도달률
- 게이트 완료율
- 상세 견적 도달률
- 상담 신청률
- 최종 유효 리드율
- 광고비 대비 유효 상담 수

중요:

- 단순 `리드 수`만 보면 완전 게이트형이 좋아 보일 수 있다.
- 그러나 실제로 봐야 하는 것은 `유효 리드 수`와 `상담 전환율`이다.

## 22. 티저 콘텐츠 설계

티저의 목적은 정보를 다 주는 것이 아니라, 사용자가 `이 결과는 내 상황에 맞춘 것이고, 더 보고 싶다`고 느끼게 하는 것이다.

### 22.1 티저 후보 비교

#### 1) 추천 시공

- 장점:
  - 개인화된 느낌이 강하다.
  - 현재 입력한 증상과 직접 연결된다.
- 단점:
  - 가격 궁금증을 직접 자극하는 힘은 약하다.

#### 2) 예상 금액대

- 장점:
  - 광고 유입 고객의 본래 질문에 가장 가깝다.
  - 다음 단계를 열어보게 만드는 힘이 강하다.
- 단점:
  - 너무 많이 보여주면 게이트의 힘이 약해진다.

#### 3) 문제 해결 메시지

- 장점:
  - 감정적 설득에 좋다.
  - 공감과 신뢰를 만든다.
- 단점:
  - 퍼널 핵심 질문인 `얼마인가`와는 거리가 있다.

### 22.2 추천 조합

가장 좋은 조합은 **추천 시공 + 금액대 일부 공개**다.

```text
당신에게는 패브릭씰러 시공이 가장 잘 맞아요
예상 금액은 약 90만~120만원 구간입니다
정확한 금액을 보려면 연락처와 지역을 입력해주세요
```

### 22.3 왜 이 조합이 좋은가

- 추천 시공이 `나를 이해했다`는 느낌을 준다.
- 금액대가 `계속 보고 싶다`는 동기를 만든다.
- 정확한 총액은 아직 잠겨 있어 게이트를 통과할 이유가 남는다.

### 22.4 티저 화면 예시

```text
┌────────────────────────────┐
│ 입력이 완료됐어요            │
│                            │
│ 당신에게 추천되는 시공       │
│ 패브릭씰러 시공              │
│ 외풍 · 냉난방비 문제에 적합   │
│                            │
│ 예상 금액대                  │
│ 약 90만 ~ 120만원            │
│                            │
│ 정확한 예상 견적을 보려면     │
│ 연락처와 지역을 입력해주세요  │
│                            │
│ 휴대폰 번호                  │
│ 지역                         │
│ [ 내 지역 기준 견적 보기 ]    │
└────────────────────────────┘
```

### 22.5 공개/비공개 기준

#### 공개

- 추천 시공
- 추천 이유
- 넓은 금액 범위
- 해당 지역 상담 가능 여부

#### 비공개

- 정확한 총액
- 옵션별 세부 비교
- 대안 견적
- 저장 가능한 결과 링크

### 22.6 문구 추천

- `당신에게는 패브릭씰러 시공이 가장 잘 맞아요`
- `예상 금액은 약 90만~120만원 구간입니다`
- `정확한 예상 견적은 지역과 현장 조건을 반영해 보여드릴게요`
- `내 지역 기준 견적 보기`

### 22.7 피해야 할 것

- 너무 작은 금액 범위 공개
- 게이트 전에 이미 충분한 결론을 준 느낌
- `연락처를 남기면 상담원이 연락드립니다`를 너무 먼저 강조하는 것
- 할인/혜택보다 먼저 압박을 주는 것

## 23. 창틀/모헤어 불확실성 처리 전략

### 23.1 문제 정의

고객은 `창틀`, `창짝`, `프로파일`, `모헤어`의 개념을 정확히 구분하지 못하는 경우가 많다.  
특히 유리를 잡고 있는 프레임을 `창짝`으로 생각하는 사용자가 많기 때문에, `창틀에도 모헤어가 있나요?` 같은 질문은 오답을 유도할 가능성이 높다.

### 23.2 원칙

- 고객에게 구조 지식을 요구하지 않는다.
- 잘못 입력할 가능성이 높은 질문은 초반 퍼널에서 제거한다.
- 최종 확정 전이라는 점은 알리되, 사용자가 실수할까 불안해지게 만들지 않는다.

### 23.3 권장안

#### 앱에서 직접 묻지 않는다

초기 퍼널에서는 창틀 모헤어 여부를 입력받지 않는다.

#### 대신 상담 단계에서 확인한다

- 전화 상담 중 사진 요청
- 필요 시 영상통화 또는 방문 확인
- 최종 금액은 확인 후 조정

#### 앱에서는 이렇게만 안내한다

```text
창호 구조에 따라 최종 금액이 달라질 수 있어요.
정확한 금액은 상담 중 사진 확인 또는 현장 확인 후 안내드립니다.
```

### 23.4 왜 이 방식이 좋은가

- 고객이 잘못 입력해 잘못된 기대를 갖는 문제를 줄인다.
- 어려운 질문 때문에 중도 이탈하는 것을 막는다.
- 상담이 필요한 이유를 자연스럽게 만든다.

### 23.5 가격 안내 방식

기본 화면에서는 `현재 입력 기준 예상 견적`만 보여준다.

추가로 아래 보조 문구를 함께 둔다.

- `창호 구조와 현장 상태에 따라 최종 금액은 달라질 수 있습니다`
- `상담 중 확인 후 더 적합한 시공 방식이나 비용 절감 방법을 함께 안내드립니다`

### 23.6 절대 피해야 할 것

- `창틀 모헤어 여부`를 고객에게 직접 묻는 것
- `최대 1.5배 상승 가능`을 초반부터 전면에 내세우는 것
- 고객이 모르는 용어를 이해한 척 답하게 만드는 것

## 24. 최종 상담 폼 구조

### 필수

- 연락처
- 상세주소

### 선택

- 메모
  - `집 상황이나 궁금한 점이 있으면 남겨주세요`

### 제거

- 이름
- 희망 일정

## 25. 고객에게 심어야 할 핵심 인식

고객은 상세 견적 화면에서 아래 세 가지를 자연스럽게 알아야 한다.

1. 에너지잡고는 `일반 모헤어 교체`와 `패브릭씰러 교체`를 모두 할 수 있다.
2. 무조건 비싼 방법을 권하는 것이 아니라, 상담을 통해 더 합리적인 방법을 함께 찾을 수 있다.
3. 앱의 금액은 확정 견적이 아니라 `상담 전 참고용 예상 견적`이다.

### 추천 문구

```text
에너지잡고는 일반 모헤어와 패브릭씰러 시공을 모두 안내합니다.
집 상태에 따라 더 합리적인 방법이 있을 수 있어요.
상담을 통해 비용을 줄일 수 있는 방향도 함께 찾아드립니다.
```

```text
지금 보시는 금액은 상담 전 참고용 예상 견적입니다.
창호 구조와 현장 상태를 확인한 뒤 최종 금액을 안내드립니다.
```
