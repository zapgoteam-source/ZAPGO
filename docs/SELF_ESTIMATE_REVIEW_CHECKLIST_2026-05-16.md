# ZAPGO 셀프견적 리뷰 보드 합의 체크리스트

## P0
- [x] 1단계 기본 선택 없음
- [x] 1단계 추천은 사용자가 선택한 뒤에만 노출
- [x] 2단계의 문자 발송 약속과 실제 경험이 일치
- [x] 3단계는 선택 → 금액 → 상담 순서
- [x] 상담 CTA는 조건과 연결된 문구 사용
- [x] 이미 받은 연락처는 재입력처럼 보이지 않음
- [x] 예상 견적 하단 문구는 짧고 안심 우선

## P1
- [x] 시공 카드 자체만으로 차이가 이해됨
- [x] 보조 문의 CTA는 메인 퍼널을 방해하지 않음
- [x] 문구는 고객 언어 중심
- [x] 개인정보 수집 이유가 명확함
- [x] 화면은 흰 캔버스, 여백 중심, 낮은 인지부하

## P2

- [x] 주소 검색 UX 실제 연동 전제 유지
- [x] 방충솔루션 추천과 수량 조정이 자연스러움
