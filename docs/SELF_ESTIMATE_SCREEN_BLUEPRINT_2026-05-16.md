# ZAPGO 셀프견적 화면 블루프린트

- 작성일: 2026-05-16
- 목적: 리디자인 전 실제 화면 구성을 거의 확정할 수 있도록, 두 핵심 화면의 콘텐츠 밀도와 인터랙션을 정의한다.

## 1. 화면 A — 빠른 입력

## 1.1 화면 목표

- 사용자가 진입 후 5초 안에 서비스 목적을 이해한다.
- 20~30초 안에 견적 화면까지 도달한다.
- 첫 화면에서 “상담 신청”보다 “바로 가격 확인”이 먼저 느껴진다.

## 1.2 추천 레이아웃

```text
┌────────────────────────────────┐
│ [LOGO]                  문의하기 │
│                                │
│ 30초 만에                      │
│ 우리 집 예상 견적 확인          │
│ 전화 없이 먼저 확인해보세요     │
│                                │
│ 불편한 점을 골라주세요          │
│ [먼지날림] [외풍유입]            │
│ [벌레유입] [냉난방비]            │
│ [소음유입] [악취유입]            │
│                                │
│ 기본 정보                      │
│ 평형                           │
│ [        25        ] 평         │
│ 창짝 개수                      │
│ [        10        ] 개         │
│ 개수 세는 방법 보기             │
│                                │
│ 추천 시공                      │
│ 패브릭씰러 · 방충솔루션          │
│                                │
│ [ 내 예상 견적 보기 ]            │
│ 카톡문의   전화문의   방문견적요청│
└────────────────────────────────┘
```

## 1.3 시각 위계

1. 헤드라인
2. 증상 선택
3. 숫자 입력 2개
4. CTA
5. 추천 시공

추천 시공은 존재해야 하지만, 메인 과업을 빼앗으면 안 된다.  
즉, “도움말”이지 “주인공”은 아니다.

## 1.4 인터랙션

- 증상 선택 시 버튼은 즉시 채워지고, 추천 시공 문구가 한 줄로 갱신된다.
- 평형/창짝 수 입력은 숫자 패드가 열린다.
- CTA는 모든 필수값 완료 전까지 비활성화한다.
- CTA 활성화 순간에만 아주 미세한 강조 애니메이션을 준다.
- `개수 세는 방법 보기`는 별도 모달로 열되, 자동 재생은 금지한다.

## 1.5 카피 후보

### Hero

- `30초 만에 우리 집 예상 견적 확인`
- `전화 없이 먼저 대략적인 금액을 확인해보세요`

### 섹션

- `불편한 점을 골라주세요`
- `기본 정보만 알려주세요`

### CTA

- `내 예상 견적 보기`

## 2. 화면 B — 견적 + 상담

## 2.1 화면 목표

- 견적이 가장 먼저 보인다.
- 고객이 금액이 어떻게 달라지는지 통제감을 느낀다.
- 상담 신청이 가격 확인의 자연스러운 다음 행동처럼 이어진다.

## 2.2 추천 레이아웃

```text
┌────────────────────────────────┐
│ 예상 견적                       │
│ 1,120,000원                     │
│ 현장 확인 후 최종 금액이 달라질 수 있어요 │
│ [결과를 문자로 받아두기]         │
│                                │
│ 어떤 시공이 맞을까요?            │
│ [추천] 패브릭씰러 시공            │
│       창문 탈거 · 4면 시공       │
│ 일반 모헤어 시공                 │
│ 측면 시공                        │
│                                │
│ 추가 옵션                        │
│ 프리미엄 보양             [토글] │
│ 방충솔루션                [토글] │
│                                │
│ 내 선택 요약                     │
│ 25평 · 창짝 10개 · 패브릭씰러     │
│                                │
│ [ 이 조건으로 상담 신청하기 ]     │
│                                │
│ ─ 클릭 후 확장 ─                 │
│ 상담을 이어갈게요                │
│ 이름                            │
│ 연락처                          │
│ 주소                            │
│ 희망 일정                        │
│ 요청사항                         │
│ [ 상담 신청 완료하기 ]            │
│                                │
│ 카톡문의   전화문의   방문견적요청 │
└────────────────────────────────┘
```

## 2.3 시각 위계

1. 총액
2. 시공 방식 선택
3. 메인 CTA
4. 옵션
5. 상담 폼

옵션은 매출에는 중요하지만, 화면 상단의 인지 부하를 키우면 총 전환이 떨어질 수 있다.  
따라서 가격과 방식 선택보다 아래에 둔다.

## 2.4 인터랙션

- 시공 방식 선택 전:
  - 총액 대신 안내 문구
  - CTA 비활성
- 시공 방식 선택 후:
  - 총액 카운트업
  - 선택 요약 노출
  - CTA 활성화
- 옵션 토글 시:
  - 총액 즉시 갱신
  - 선택 요약 문구 갱신
- 상담 CTA 클릭 시:
  - 같은 페이지 내 폼 확장
  - 폼 영역으로 자연스럽게 스크롤
  - 상단 견적 요약은 sticky summary로 남김

## 2.5 카피 후보

### 총액 영역

- `예상 견적`
- `현장 확인 후 최종 금액은 달라질 수 있어요`

### 방식 선택

- `어떤 시공이 맞을까요?`

### CTA

- `이 조건으로 상담 신청하기`
- `상담 신청 완료하기`

### 보조 액션

- `결과를 문자로 받아두기`
- `방문 견적 먼저 요청하기`

## 3. 화면 상태별 설계

## 3.1 첫 진입

- 입력 이력 없음
- 첫 화면 A 노출
- headline 중심

## 3.2 문자 링크 재진입

- 화면 B 직접 진입
- 기존 선택값 복원
- 상단에 `저장한 견적을 다시 불러왔어요`

## 3.3 대리점 링크 진입

- 첫 화면 상단에 얇은 배너
  - `OO대리점 추천 링크로 접속하셨습니다`
- 과한 공동 브랜딩은 지양

## 4. CTA 체계

## 4.1 Primary

- 화면 A: `내 예상 견적 보기`
- 화면 B: `이 조건으로 상담 신청하기`

## 4.2 Secondary

- `결과를 문자로 받아두기`
- `방문견적요청`

## 4.3 Utility

- `카톡문의`
- `전화문의`

## 5. 반응형 원칙

- 390px 기준 1열
- 768px 이상에서도 모바일 구조 유지 가능
- 데스크톱에서는 폭을 넓히기보다 카드 폭만 확장
- 하단 고정 CTA는 모바일에서만 강하게 유지

## 6. 시각 톤 제안

### 6.1 색

- Primary Red
- Ivory Background
- Warm Gray Surface
- Deep Charcoal Text

### 6.2 형태

- 둥근 모서리는 과하지 않게
- 지나친 그림자보다 면 분리
- 컴포넌트는 얇고 정제된 느낌

### 6.3 분위기

- “전문 시공 브랜드”
- “복잡한 계산을 쉽게 풀어주는 도구”
- “세일즈 압박보다 신뢰”

## 7. 최종 추천

이 리디자인의 승부처는 두 군데다.

1. 첫 화면에서 얼마나 빨리 사용자가 `여기서 바로 확인 가능하구나`를 느끼는가
2. 견적을 본 직후, 상담 신청이 얼마나 자연스럽게 한 번의 흐름으로 이어지는가

이 두 순간이 매끄러워지면, 페이지 수 축소보다 더 큰 효과가 난다.

## 8. 광고 유입형 최종 퍼널 블루프린트

광고 중심 리드 퍼널에서는 최종적으로 아래 3단계 구조를 권장한다.

```text
1. 빠른 입력
2. 티저 + 리드 게이트
3. 상세 견적 + 상담 전환
```

## 8.1 Step 1 — 빠른 입력

### 목표

- 호기심을 행동으로 바꾼다.
- 사용자가 `나도 확인해볼까` 상태에서 실제 입력을 시작하게 만든다.

### 입력

- 불편 증상
- 평형
- 창짝 수

### 출력

- 다음 단계로 넘어갈 최소 진단 데이터

### CTA

- `내 예상 견적 확인하기`

## 8.2 Step 2 — 티저 + 리드 게이트

### 목표

- 작은 보상을 주고, 정확한 결과를 보기 위한 리드를 확보한다.

### 공개 정보

- 추천 시공
- 추천 이유
- 넓은 금액 범위

### 입력

- 휴대폰 번호
- 지역

### CTA

- `내 지역 기준 견적 보기`

### 예시

```text
당신에게는 패브릭씰러 시공이 가장 잘 맞아요
예상 금액은 약 90만~120만원 구간입니다

정확한 예상 견적을 보려면
휴대폰 번호와 지역을 입력해주세요

[ 휴대폰 번호 ]
[ 지역 ]
[ 내 지역 기준 견적 보기 ]
```

## 8.3 Step 3 — 상세 견적 + 상담 전환

### 목표

- 상세 결과를 보여주고, 상담 신청을 닫는다.

### 공개 정보

- 정확한 총액
- 시공 방식 선택/비교
- 옵션 조정
- 선택 요약

### 입력

- 이름
- 상세 주소
- 희망 일정
- 요청사항

### CTA

- `이 조건으로 상담 신청하기`

### 전환 장치

- 결과 문자 저장
- 카톡문의
- 전화문의
- 방문견적요청

## 8.4 최종 흐름

```text
광고 클릭
 ↓
빠른 입력
 ↓
추천 시공 + 예상 금액대
 ↓
휴대폰 번호 + 지역
 ↓
정확한 상세 견적
 ↓
상담 신청
```

## 8.5 왜 3단계인가

- 1단계는 **행동 시작**
- 2단계는 **리드 확보**
- 3단계는 **상담 전환**

각 단계가 맡는 역할이 다르기 때문에, 광고 유입에서는 무리하게 2단계로 압축하기보다 3단계가 오히려 더 자연스럽다.

## 9. 상세 견적 화면의 불확실성 표현

### 9.1 직접 묻지 않을 것

- 창틀 모헤어 여부
- 창틀/창짝 구분
- 고객이 구조 지식을 알아야 답할 수 있는 질문

### 9.2 대신 보여줄 것

```text
현재 입력 기준 예상 견적
1,120,000원

창호 구조와 현장 상태에 따라 최종 금액은 달라질 수 있어요.
정확한 금액은 상담 중 사진 확인 또는 현장 확인 후 안내드립니다.
```

### 9.3 함께 보여줄 보완 메시지

```text
에너지잡고는 일반 모헤어 교체와 패브릭씰러 교체를 모두 안내합니다.
집 상태에 따라 더 합리적인 방법이 있을 수 있어요.
상담을 통해 비용을 줄일 수 있는 방향도 함께 찾아드립니다.
```

### 9.4 상담 폼 최종 구조

```text
연락처 *
상세주소 *
메모 (선택)
[ 상담 신청하기 ]
```

### 9.5 메모 placeholder

- `집 상황이나 궁금한 점이 있으면 자유롭게 남겨주세요`
