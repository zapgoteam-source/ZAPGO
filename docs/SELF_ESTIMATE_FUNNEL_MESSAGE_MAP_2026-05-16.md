# ZAPGO 셀프견적 퍼널 메시지 맵

- 작성일: 2026-05-16
- 목적: 광고 유입 고객이 왜 다음 단계로 넘어가야 하는지, 단계별 심리와 카피를 한 장으로 정리한다.

## 1. 전체 퍼널

```text
관심
 ↓
입력
 ↓
궁금증 증폭
 ↓
리드 확보
 ↓
상담 전환
```

## 2. 단계별 설계

## 2.1 Step 1 — 빠른 입력

### 고객 마음

- `어? 나도 해당되나?`
- `얼마인지 궁금하네`

### 해야 할 일

- 입력 시작 장벽을 낮춘다.
- 결과가 금방 나온다는 확신을 준다.

### 핵심 카피

- `30초 만에 우리 집 예상 견적 확인`
- `전화 없이 먼저 대략적인 금액을 확인해보세요`

### 행동

- 증상 선택
- 평형 입력
- 창짝 수 입력

### CTA

- `내 예상 견적 확인하기`

### 피해야 할 것

- 과한 설명
- 자동 재생 영상
- 초기 상담 압박

## 2.2 Step 2 — 티저 + 게이트

### 고객 마음

- `내 상황에 맞는 결과가 나왔네`
- `정확히 얼마인지 더 보고 싶다`

### 해야 할 일

- 개인화 감각을 준다.
- 결과를 일부 공개해 궁금증을 키운다.
- 연락처 요청을 자연스럽게 정당화한다.

### 핵심 카피

- `당신에게는 패브릭씰러 시공이 가장 잘 맞아요`
- `예상 금액은 약 90만~120만원 구간입니다`
- `정확한 내 지역 기준 견적을 보려면 휴대폰 번호와 지역을 입력해주세요`

### 행동

- 휴대폰 번호 입력
- 지역 입력

### CTA

- `내 지역 기준 견적 보기`

### 피해야 할 것

- `상담원이 연락드립니다`를 너무 먼저 강조
- 너무 정확한 가격 공개
- 지역 대신 상세 주소 요구

## 2.3 Step 3 — 상세 견적 + 상담 전환

### 고객 마음

- `이 정도면 괜찮네`
- `그럼 상담 한번 받아볼까`

### 해야 할 일

- 총액을 명확히 보여준다.
- 사용자가 통제감을 느끼게 한다.
- 상담 신청을 자연스러운 다음 행동으로 만든다.

### 핵심 카피

- `예상 견적`
- `현장 확인 후 최종 금액은 달라질 수 있어요`
- `이 조건으로 상담 신청하기`
- `집 상태에 따라 더 합리적인 방법이 있을 수 있어요`
- `상담을 통해 비용을 줄일 수 있는 방향도 함께 찾아드립니다`

### 행동

- 시공 방식 선택
- 옵션 조정
- 상담 신청

### CTA

- `이 조건으로 상담 신청하기`
- `상담 신청 완료하기`

### 피해야 할 것

- 긴 폼을 처음부터 전부 노출
- CTA 여러 개가 같은 위계로 경쟁
- 상담 신청을 별도 페이지 업무처럼 느끼게 하는 것
- 창틀/창짝 구분처럼 고객이 헷갈릴 수 있는 구조 질문

## 3. 광고 문구와 랜딩의 연결

## 3.1 광고에서 약속할 것

- `우리 집 창문 시공, 얼마인지 30초 만에 확인`
- `외풍·먼지·벌레 유입, 내 집에 맞는 시공 방식 확인`

## 3.2 랜딩에서 즉시 이어받을 것

- 같은 키워드
- 같은 문제 언어
- 같은 보상

### 원칙

광고에서 던진 질문을 랜딩 첫 화면이 바로 받아야 한다.  
광고는 호기심을 만들고, 랜딩은 그 호기심을 절대 새지 않게 붙잡아야 한다.

## 4. 설득 장치

### 4.1 호기심

- `얼마인지 바로 확인`

### 4.2 자기 관련성

- 증상 기반 추천

### 4.3 불완전한 보상

- 넓은 금액 범위만 먼저 공개

### 4.4 통제감

- 옵션 조정에 따라 금액 변화

### 4.5 손쉬운 다음 행동

- 같은 화면 내 상담 신청

## 5. KPI와 연결

| 단계 | 핵심 KPI |
|---|---|
| Step 1 | 입력 시작률, 입력 완료율 |
| Step 2 | 게이트 도달률, 게이트 완료율 |
| Step 3 | 상세 견적 도달률, 상담 신청률 |

## 6. 최종 메시지 원칙

1. 초반에는 팔지 말고, 궁금하게 만든다.
2. 중간에는 다 보여주지 말고, 더 보고 싶게 만든다.
3. 마지막에는 복잡하게 설명하지 말고, 바로 신청하게 만든다.
