# ZAPGO 셀프견적 2차 리뷰 라운드 정리

## 이번 라운드의 핵심 질문

이미 기본 전환 흐름은 성립한 상태에서, 광고 유입 고객을 더 많이 상담까지 데려가기 위해 남아 있는 구조적 저항은 무엇인가?

## 리뷰어 합의

### 1. 2단계 리드 게이트 직전에는 설명보다 신뢰가 더 필요하다

- 연락처와 주소 입력은 여전히 가장 큰 이탈 후보
- 고객은 `왜 필요한가`보다 `입력해도 괜찮은가`를 먼저 판단할 수 있음
- 짧은 신뢰 증거를 금액대 근처에 두는 편이 유리

### 2. 문자 발송은 재방문 장치로 쓰고, 현재 세션은 끊지 않는 편이 낫다

- 문자를 보내더라도 고객이 앱 안에서 바로 이어서 볼 수 있어야 함
- 광고 유입의 열기는 식기 전에 다음 행동으로 연결해야 함

### 3. 3단계는 자유 탐색보다 순차적 결정 흐름이 더 적합하다

- 시공 방식, 보양, 방충, 금액, 상담 폼이 한 번에 보이면 선택 피로가 생김
- 한 선택이 끝날 때마다 다음 블록이 열리는 구조가 더 낮은 인지부하를 만든다

### 4. 상담 신청은 별도 폼이 아니라, 견적 확인의 마지막 마무리처럼 느껴져야 한다

- `또 입력해야 한다`가 아니라 `이 조건으로 확인받기`에 가까운 구조가 바람직
- 상담 직전에는 신뢰 장치를 다시 한 번 주는 편이 전환에 유리

## 이번 라운드에서 즉시 반영한 것

1. 2단계 예상 금액대 아래 신뢰 태그 추가
   - 집 상태에 맞춰 비교
   - 과한 시공 없이 안내
   - 상담 전 예상 비용 확인

2. 문자 발송 완료 화면 문구 수정
   - 문자 링크로 재방문 가능
   - 현재 화면에서도 바로 이어서 확인 가능

3. 3단계 순차 노출 구조 적용
   - 시공 방식 선택 전에는 보양 미노출
   - 보양 선택 전에는 방충/금액/FAQ/상담 폼 미노출
   - 선택을 마칠수록 다음 단계가 자연스럽게 열린다

4. 상담 직전 신뢰 태그 추가
   - 사진·상태 함께 확인
   - 여러 방법 비교 안내
   - 과한 시공은 권하지 않음

## 이번 라운드에서 보류한 실험

### A. 2단계 게이트 완화

- 현재: 연락처 + 주소
- 실험 후보: 연락처만 먼저 받고 상세 견적 공개, 주소는 상담 직전 입력
- 이유: 유효 리드율과 최종 상담 전환율 사이의 균형을 실제 데이터로 봐야 함

### B. 추천안 우선형 3단계

- 현재: 고객이 직접 시공 방식을 먼저 고름
- 실험 후보: 추천 조합 먼저 제시, 다른 방식은 펼쳐서 비교
- 이유: 전환에는 유리할 수 있지만, 현재 사용자가 중요하게 본 `직접 비교·조정 경험`과 충돌 가능

### C. 광고 소재별 랜딩 분기

- 벌레 광고 / 외풍 광고 / 대리점 링크마다 첫 화면과 기본 맥락 분기
- 이유: 효과는 클 가능성이 높지만, 광고 캠페인 구조와 연결해야 해서 별도 구현 라운드가 적절

## 다음 의사결정 포인트

1. 주소를 2단계에서 계속 받을지, 상담 직전으로 늦출지
2. 3단계에서 자유 선택을 유지할지, 추천안 우선형을 시험할지
3. 광고 유입별 랜딩 분기를 다음 구현 라운드에 넣을지
