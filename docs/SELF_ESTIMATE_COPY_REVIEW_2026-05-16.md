# ZAPGO 셀프견적 프로토타입 문구 검토본

목적: 현재 프로토타입에 노출되는 모든 사용자 문구를 한곳에 모아, 톤앤매너·중복·전환 관점에서 함께 검토하고 수정하기 위함.

검토 권장 기준:
- 고객이 바로 이해하는가
- 불필요하게 설명이 길지 않은가
- 다음 행동을 자연스럽게 유도하는가
- 불안은 줄이고, 과장은 피하는가
- 같은 의미가 여러 번 반복되지 않는가
